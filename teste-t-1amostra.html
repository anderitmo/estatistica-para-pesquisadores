Teste t (1 Amostra)

A média difere de um valor de referência?

Como este cálculo ajuda

O que calcula

Compara a média amostral a μ₀ e retorna t, gl, p-valor e decisão.

Contribuição acadêmica

Teste paramétrico clássico para uma média com σ desconhecido.

Exemplo simples

Teste t para verificar se o peso médio ao nascer de uma amostra de bebês difere de μ₀ = 2.1 kg ao nível de 5% de significância (Louzada et al., 2026, p. 141).

Método, uso e referência

Fórmula central

t = (x̄ − μ₀) / (s/√n)

Quando usar

Aplique o Teste t para 1 Amostra para verificar se a média calculada a partir de um conjunto de dados quantitativos difere de forma estatisticamente significativa de um valor de referência ou padrão conhecido (μ₀).

Referências

• Louzada, F., Ferreira, P. H., & Ramos, P. L. (2026). Estatística Básica com Suporte Computacional. São Carlos: Ed. dos Autores.

Instruções para Linguagem R

Você pode replicar estes mesmos cálculos no R ou executá-los gratuitamente na nuvem via Google Colab (utilizando %load_ext rpy2.ipython e %%R):

%%R
# Exemplo: Teste t de uma amostra contra mu0 = 2.1 kg (Louzada et al., 2026, p. 141)
x <- c(2.15, 2.20, 2.05, 2.30, 2.25, 2.10, 2.18, 2.22)
t.test(x, mu=2.1, alternative='two.sided')
