Fator de Correção (População Finita)

Ajuste do erro padrão para amostragem sem reposição em populações finitas conhecidas.

Como este cálculo ajuda

O que calcula

Calcula o Fator de Correção para População Finita (FCP = √[(N−n)/(N−1)]) e o erro padrão ajustado da média.

Contribuição acadêmica

Quando a amostra representa mais de 5% de uma população conhecida (n/N ≥ 0,05), o FCP reduz o erro padrão e gera intervalos de confiança mais precisos.

Exemplo simples

População N = 1000, amostra n = 100 (10%), desvio padrão s = 15 (Louzada et al., 2026, Cap. 4, p. 113). O FCP é 0,9491 e o erro padrão passa de 1,5000 para 1,4237.

Método, uso e referência

Fórmula central

FCP = √[ (N − n) / (N − 1) ]  |  EP_ajustado = (s / √n) · FCP

Quando usar

Utilize esta calculadora quando estiver realizando uma amostragem aleatória sem reposição de uma população finita de tamanho N conhecido e a fração amostral n/N for maior que 5% (n/N ≥ 0,05).

Referências

• Louzada, F., Ferreira, P. H., & Ramos, P. L. (2026). Estatística Básica com Suporte Computacional. São Carlos: Ed. dos Autores.

Instruções para Linguagem R

Você pode replicar estes mesmos cálculos no R ou executá-los gratuitamente na nuvem via Google Colab:

%%R
# Exemplo FCP (Louzada et al., 2026, p. 113)
N <- 1000; n <- 100; s <- 15
fpc <- sqrt((N - n) / (N - 1))
ep_raw <- s / sqrt(n)
ep_adj <- ep_raw * fpc
c(fpc = fpc, ep_raw = ep_raw, ep_adj = ep_adj)
