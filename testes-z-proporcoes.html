Testes Z para Proporções

Teste de hipóteses e intervalos de confiança para uma ou duas proporções binárias.

Como este cálculo ajuda

O que calcula

Calcula o escore Z, p-valores e intervalos de confiança (incluindo o método Wilson Score para uma amostra) para proporções.

Contribuição acadêmica

Permite testar e comparar taxas de prevalência, incidência de desfechos clínicos, proporções de mercado ou de intenção de voto em dados categóricos dicotômicos.

Exemplo simples

Teste de proporção populacional baseada em amostra de n = 100 com x = 8 homens daltônicos contra a referência p₀ = 0.08 (8%) (Louzada et al., 2026, Ex. 5, p. 131).

Método, uso e referência

Fórmula central

Z = (p̂ − p₀) / √[ p₀(1−p₀) / n ]

Quando usar

Utilize o Teste Z para Proporções para comparar a proporção observada de sucessos de uma amostra contra uma proporção populacional teórica (1 amostra) ou para comparar as proporções de dois grupos independentes (2 amostras).

Referências

• Louzada, F., Ferreira, P. H., & Ramos, P. L. (2026). Estatística Básica com Suporte Computacional. São Carlos: Ed. dos Autores.
