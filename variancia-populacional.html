Variância Populacional

Intervalo de confiança e teste de hipóteses para a variância (σ²) e desvio padrão (σ).

Como este cálculo ajuda

O que calcula

Calcula o Intervalo de Confiança para a variância populacional σ² (e σ) e realiza o teste de hipóteses H₀: σ² = σ²₀ baseado na distribuição Qui-Quadrado (χ²).

Contribuição acadêmica

Permite estimar a variabilidade e a precisão em processos populacionais e testar se a variância amostral difere significativamente de um valor de referência.

Exemplo simples

Pesos de 10 ratos de laboratório (Louzada et al., 2026, Cap. 5, p. 146). Variância amostral s² = 1703,11 g². O IC 95% para σ² é [808,61 ; 5220,13].

Método, uso e referência

Fórmula central

χ² = (n − 1) · s² / σ²  |  IC 95%: [ (n−1)s² / χ²_superior ; (n−1)s² / χ²_inferior ]

Quando usar

Utilize esta calculadora quando o foco do estudo for inferir a variabilidade (dispersão) da população a partir de uma amostra. Requer o pressuposto de que os dados sigam uma distribuição Normal.

Referências

• Louzada, F., Ferreira, P. H., & Ramos, P. L. (2026). Estatística Básica com Suporte Computacional. São Carlos: Ed. dos Autores.

Instruções para Linguagem R

Você pode replicar estes mesmos cálculos no R ou executá-los gratuitamente na nuvem via Google Colab:

%%R
# Exemplo: Variância de 10 ratos (Louzada et al., 2026, p. 146)
x <- c(241, 228, 126, 259, 206, 201, 233, 151, 197, 165)
n <- length(x); s2 <- var(x)
alpha <- 0.05
ic_var <- c((n-1)*s2 / qchisq(1-alpha/2, n-1), (n-1)*s2 / qchisq(alpha/2, n-1))
ic_var
