Regressão Linear Simples

Modela e prevê Y a partir de X por uma reta.

Como este cálculo ajuda

O que calcula

Estima intercepto, inclinação, R² e a significância do coeficiente.

Contribuição acadêmica

Permite previsão e quantifica o efeito de X sobre Y.

Exemplo simples

Ajuste de modelo de regressão linear simples Y = a + bX via mínimos quadrados (Louzada et al., 2026, Cap. 8, p. 224). Pares X,Y: (2, 25), (4, 30), (6, 35), (8, 40). Equação: Y = 20 + 2.5·X.

Método, uso e referência

Fórmula central

Y = a + bX (mínimos quadrados)

Quando usar

Relação linear entre duas quantitativas; resíduos bem-comportados.

Referências

• Louzada, F., Ferreira, P. H., & Ramos, P. L. (2026). Estatística Básica com Suporte Computacional. São Carlos: Ed. dos Autores.

Instruções para Linguagem R

Você pode replicar estes mesmos cálculos no R ou executá-los gratuitamente na nuvem via Google Colab (utilizando %load_ext rpy2.ipython e %%R):

%%R
x <- c(2, 4, 6, 8)
y <- c(25, 30, 35, 40)
mod <- lm(y ~ x)
summary(mod)
