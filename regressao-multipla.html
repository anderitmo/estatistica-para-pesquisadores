Regressão Múltipla

Modela Y a partir de vários preditores simultaneamente.

Como este cálculo ajuda

O que calcula

Estima coeficientes (MQO), erros-padrão, t, p, R² e R² ajustado.

Contribuição acadêmica

Isola o efeito de cada preditor controlando os demais.

Exemplo simples

Regressão linear múltipla Y ~ X1 + X2 com 5 observações: X1=[1,2,3,4,5], X2=[2,1,4,3,6], Y=[3,2,7,6,11]. R² = 0,98.

Método, uso e referência

Fórmula central

Y = β₀ + β₁X₁ + … + βₚXₚ

Quando usar

Utilize a Regressão Múltipla para modelar a relação entre uma variável resposta contínua (Y) e dois ou mais preditores independentes (X1, X2, ...), permitindo avaliar o efeito isolado de cada variável ajustado pelas demais.

Referências

• Guimarães, P. R. B. (2008). Métodos Quantitativos Estatísticos. Curitiba: IESDE Brasil. Cap. Análise de Regressão (p. 189–200).

Instruções para Linguagem R

Você pode replicar estes mesmos cálculos no R ou executá-los gratuitamente na nuvem via Google Colab (utilizando %load_ext rpy2.ipython e %%R):

%%R
# Exemplo: Ajuste de regressão linear múltipla Y ~ X1 + X2
x1 <- c(1, 2, 3, 4, 5); x2 <- c(2, 1, 4, 3, 6); y <- c(3, 2, 7, 6, 11)
summary(lm(y ~ x1 + x2))
